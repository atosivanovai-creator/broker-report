# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии со страницы [Releases](../../releases).

## Как сообщить об уязвимости

Не создавайте публичную задачу (Issue). Воспользуйтесь закрытым сообщением:
вкладка **Security → Report a vulnerability** этого репозитория (GitHub Private Vulnerability Reporting).

Опишите, что можно сделать и при каких условиях, версию программы и шаги воспроизведения. Не прикладывайте
настоящие справки, ключи API и номера счетов. Ответ — в течение 7 дней; исправление и публикация — по
договорённости с вами.

## Что программа защищает

- **Справки** — только на этом компьютере (`%LOCALAPPDATA%\BrokerReport`); сервер слушает только `127.0.0.1`.
  Формы защищены случайным токеном от запросов чужих страниц (CSRF).
- **Ключ Finam Trade API** — шифруется Windows DPAPI (привязка к пользователю Windows), в окне и журнале не
  показывается; уходит только на `api.finam.ru` (в теле запроса входа). Временный токен доступа отправляется
  только на `api.finam.ru` и адреса `*.finam.ru`.
- **Торговля** — в программе нет функций выставления и снятия заявок. Рекомендуется ключ «только просмотр»;
  ключ с правом торговли принимается только с явной отметкой «Разрешить торговый ключ».

## Вне рамок

Защита от вредоносной программы, уже запущенной под тем же пользователем Windows: она может прочитать справки
и расшифровать ключ так же, как сама программа.
