# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.6] — 2026-10-30

- В отчёт добавлены новые инструменты.
- Косметические исправления графиков.

## [1.0.5] — 2026-10-29

### Изменено
- Если брокер отказал в справке по ключу «только просмотр», программа прямо пишет, что делать: создать ключ
  с правом торговли и подключить его с отметкой «Разрешить торговый ключ». Квота при таком отказе не тратится.
- Подсказки в блоке «Автозагрузка» и README: ключ «только просмотр» — рекомендуемый, торговый — если брокер
  откажет по нему в справке.

## [1.0.4] — 2026-10-29

### Добавлено
- Автозагрузка справок через Finam Trade API: при запуске программы и по расписанию Windows (07:30, 13:30,
  19:30). Справка заказывается, только если её нет и сегодня она ещё не была получена; неудачная попытка
  повторяется следующим запуском. Пробел закрывается одной справкой (до 92 дней); справка, которая ещё
  собирается, забирается по номеру заказа без нового заказа.
- `BrokerReportFetch.exe` — фоновая загрузка без окна консоли (для Планировщика Windows).
- Ключ API хранится зашифрованным (DPAPI); ключи с правом торговли не принимаются без явного разрешения.

### Изменено
- Новая стартовая страница: шаги «скачайте — загрузите — откройте», поле для перетаскивания файлов,
  карточки счетов.
- Проценты брокера на остаток показываются «к выплате», НДФЛ с них — днём выплаты (раньше налог попадал
  в разложение дважды, «доходы» были занижены).

## [1.0.3] — 2026-10-28

### Изменено
- Шапки таблиц: подписи по центру, перенос только по словам, группы колонок с подчёркиванием; фильтр — значком
  в шапке вместо строки фильтров.
- «Ценные бумаги» и «По дням» помещаются на экран 1366 px без прокрутки; «Ценные бумаги» запоминают колонки.

## [1.0.2] — 2026-10-28

### Добавлено
- Блок «Ценные бумаги»: облигации, акции, фонды по ISIN, проверка количества, строка «Валюта».

### Исправлено
- ВМ сводки больше не включает деньги за купленные, но ещё не поставленные бумаги (ВМ года покупки и
  следующего года сдвигались на эту сумму; прибыль не менялась).

## [1.0.1] — 2026-10-28

### Исправлено
- Склейка справок не теряет сделки, оплаченные после стыка справок (сделка вечером 30.12 с оплатой 05.01).

## [1.0.0] — 2026-10-28
