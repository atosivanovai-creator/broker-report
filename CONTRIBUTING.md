# Участие в разработке

Спасибо за интерес к BrokerReport! Ошибки, предложения и исправления приветствуются.

## Сообщить об ошибке

Создайте задачу в [Issues](../../issues) по шаблону «Ошибка». Укажите версию программы, версию Windows,
что делали и что увидели.

**Справки содержат персональные данные.** Если ошибка в разборе справки, не прикладывайте её целиком:
- удалите или замените номер счёта («По счету: КлФ-…»), ФИО, адрес, номера договоров;
- по возможности оставьте только таблицу, в которой ошибка, и замените суммы на вымышленные;
- проверьте, что ошибка воспроизводится на обезличенном файле.

Уязвимости — не в Issues, а по [SECURITY.md](SECURITY.md).

## Предложить изменение

1. Форк → ветка от `main`.
2. Окружение (Windows, Python 3.12):
   ```powershell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt
   ```
3. Изменение + тест к нему в `tests/` (pytest). Тесты — только на синтетических справках (см.
   `tests/test_brep_old_format.py::_report`), настоящие справки в репозиторий не добавляются.
4. `.venv\Scripts\python -m pytest tests` — все тесты зелёные; для изменений окна — сквозная проверка
   `tests/e2e_check.py` на запущенной программе.
5. Pull Request с описанием: что меняется, зачем и чем проверено.

## Правила кода

- Расчёт — в `brep/` (разбор `brep_parse.py`, модель `brep_model.py`, окно `brep_view.py`); приём справок —
  `intake.py`; автозагрузка через API — `finam_fetch.py` (только стандартная библиотека Python).
- Деньги сверяются с итогами брокера — изменение разбора не должно ломать сверку; нераспознанное лучше
  показать человеку (⚠), чем тихо посчитать неверно.
- Никаких функций выставления заявок и обращений к сетевым адресам, кроме `api.finam.ru`.

Участвуя, вы соглашаетесь с [правилами поведения](CODE_OF_CONDUCT.md) и с тем, что ваш вклад
распространяется по лицензии [MIT](LICENSE).
