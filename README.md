# BrokerReport

[![CI](https://github.com/atosivanovai-creator/broker-report/actions/workflows/ci.yml/badge.svg)](https://github.com/atosivanovai-creator/broker-report/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
![Windows](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6)

Бесплатная программа для Windows: отчёт по брокерскому счёту ФИНАМ из «Справок о состоянии обязательств».
Прибыль и доходность по годам, затраты, результат по фьючерсам и ценным бумагам, графики.

Всё считается на вашем компьютере, справки никуда не отправляются. В интернет программа обращается только
к `api.finam.ru` — если вы подключили ключ для автозагрузки справок.

> Неофициальная программа, не связана с АО «ФИНАМ». Не является инвестиционной рекомендацией.

![Стартовая страница](docs/screenshots/home.png)

## Возможности

- **Сводка по годам** — стоимость счёта, ввод и вывод, прибыль и доходность, ВМ, купоны, затраты, налоги, ГО, просадка.
- **Фьючерсы** — сделки, лоты, результат и затраты по каждому инструменту.
- **Ценные бумаги** — облигации, акции и фонды, по каждой бумаге.
- **По дням** — те же показатели по дням, неделям и месяцам.
- **Графики** — доходность, просадка, стоимость счёта, месяцы, затраты, доход по инструментам.
- **Сверка с брокером** — каждая справка сверяется с итогами брокера до копейки.
- **Автозагрузка** — справки скачиваются сами через Finam Trade API.

## Установка

1. Скачайте `BrokerReport-<версия>-win64.zip` со страницы [Releases](../../releases).
2. Распакуйте в любую папку и запустите `BrokerReport.exe` — отчёт откроется в браузере.
   Чтобы остановить программу, закройте её консольное окно.
3. Если Windows SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

Целостность архива можно проверить по `SHA256SUMS.txt` (PowerShell: `Get-FileHash BrokerReport-*.zip`).

Ключи запуска: `--port 8766` (другой порт), `--no-browser`, `--data D:\папка` (свой каталог данных),
`--no-fetch` (не запрашивать справки при запуске).

## Какие справки нужны

«Справка о состоянии обязательств» из личного кабинета ФИНАМ — файлом `.xls` или `.html`, либо zip-архив
из кабинета как есть.

- Счёт и период программа берёт из самой справки, имена файлов не важны.
- Лучше брать справки по календарным годам: одна справка за несколько лет по годам не делится.
- Повторная загрузка справки за тот же период заменяет прежнюю.

## Ценные бумаги

По каждой бумаге: количество и оценка на начало и конец, покупки, продажи, погашения, купоны, комиссии и
результат. Программа проверяет количество (начало + куплено − продано − погашено = конец): ✓ — сошлось,
⚠ — нет, такой строке не доверяйте. Операции, которые программа не знает, перечисляются под таблицей.

## Автозагрузка справок

1. На портале [Finam Trade API](https://api.finam.ru/) → «Токены» создайте ключ с доступом «только просмотр»
   и отметьте нужные счета.
2. На странице «Счета» в блоке «Автозагрузка» вставьте ключ и нажмите «Подключить ключ».
3. По желанию — «Включить расписание»: справки будут загружаться в 07:30, 13:30 и 19:30,
   а если компьютер был выключен — при включении.

Справка заказывается не чаще раза в день на счёт и только если её ещё нет. Ключ хранится зашифрованным
средствами Windows и в окне больше не показывается. Если брокер откажет в справке по ключу «только просмотр»,
программа подскажет, что делать. Заявок программа не выставляет.

## Где данные

`%LOCALAPPDATA%\BrokerReport`: `reports` — загруженные справки, `cache` — кэш разбора, `api.json` —
зашифрованные ключи API, `api-state.json` и `api.log` — состояние и журнал автозагрузки.
Кнопки «удалить» (счёт) и «Удалить все данные» на странице «Счета» стирают их.

## Сборка из исходников

Нужен Python 3.12 (Windows).

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt
.venv\Scripts\python -m pytest tests
.venv\Scripts\python build.py        # dist\BrokerReport-<версия>-win64.zip
```

Без сборки: `.venv\Scripts\python app.py`. Релизы собираются в GitHub Actions из тега `v*`
(`.github/workflows/release.yml`): архив и `SHA256SUMS.txt` прикладываются к релизу. История изменений —
[CHANGELOG.md](CHANGELOG.md).
