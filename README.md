BrokerReport — отчёт брокера по справкам ФИНАМ
==============================================

Бесплатная программа для Windows: загружаете «Справки о состоянии обязательств» ФИНАМ — получаете
сводку по календарным годам (деньги, доход, затраты, риск, оборот), разбивку по инструментам срочного рынка,
блок «Ценные бумаги» (облигации, акции, фонды — по ISIN), разбивку по дням и окно графиков (доходность,
просадка, стоимость счёта, месяцы, затраты).

Всё считается на вашем компьютере. Программа открывает страницу в браузере по адресу
http://127.0.0.1:8765/ и слушает только этот компьютер; справки никуда не отправляются. В интернет программа
обращается только к api.finam.ru — и только если вы подключили ключ Trade API (см. «Автозагрузка»).

Неофициальная программа, не связана с АО «ФИНАМ». Не является инвестиционной рекомендацией.


Запуск
------
1. Распакуйте архив BrokerReport-<версия>-win64.zip в любую папку.
2. Запустите BrokerReport.exe — откроется консольное окно и страница «Счета» в браузере.
   Закройте консольное окно, чтобы остановить программу.
3. Если Windows SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

Ключи запуска: --port 8766 (другой порт), --no-browser, --data D:\папка (свой каталог данных),
--no-fetch (не запрашивать справки при запуске).


Какие справки нужны
-------------------
«Справка о состоянии обязательств» из личного кабинета ФИНАМ, файлом .xls или .html (внутри — HTML),
либо zip-архив из кабинета как есть: вложенные архивы распаковываются, файлы подписи .sga пропускаются.

- Счёт и период программа берёт из шапки справки, имена файлов не важны. Несколько счетов — каждый отдельно.
- Лучше справки по календарным годам (текущий год — по сегодняшний день): стоимость счёта известна только
  на концах справок, поэтому одна справка за несколько лет по годам не делится.
- Повторная загрузка справки за тот же период заменяет прежнюю.
- В строке «сверка с итогами брокера» программа показывает, у скольких справок сумма разобранных строк
  совпала с итогами брокера «Виды движений денежных средств» до копейки.


Ценные бумаги
-------------
По каждой бумаге (ISIN): количество и оценка брокера (с НКД) на начало и конец периода, куплено, продано,
погашено, купоны и дивиденды, комиссии, результат и проверка количества: начало + куплено − продано −
погашено должно равняться концу. ✓ — сошлось, ⚠ — нет (такой строке не доверяйте). Позиция — как у
брокера в «Оценке обязательств по незавершённым сделкам»: с купленными, но ещё не поставленными бумагами
и бумагами, выданными брокеру в займ. Операции, которые программа не знает, перечисляются под таблицей.
Строка «Валюта» — покупки и продажи валюты.


Автозагрузка через API ФИНАМ
----------------------------
Справки можно не скачивать руками: программа сама заказывает у брокера справку за прошедшие дни через
Finam Trade API (https://api.finam.ru/).

1. На портале Trade API → «Токены» создайте ключ с доступом «только просмотр» и отметьте нужные счета.
2. На странице «Счета» в блоке «Автозагрузка» вставьте ключ и нажмите «Подключить ключ».
3. По желанию — «Включить расписание»: задача «BrokerReport - справки ФИНАМ» в Планировщике Windows
   запускает загрузку 3 раза в день (07:30, 13:30, 19:30; если компьютер был выключен — при включении),
   без окна и без открытой программы.

Правило запроса: справка заказывается, только если её ещё нет и сегодня она ещё не была получена. Удачная
загрузка ставит отметку «за сегодня получено» — следующие запуски в этот день к брокеру не обращаются.
Неудача (нет связи, справка не собралась, исчерпана квота) отметки не ставит — следующий запуск пробует снова.
Пропуск в несколько дней закрывается одной справкой (до 92 дней — предел API); брокер даёт 3 заказа справок
в сутки на клиента, программа тратит не больше одного в день на счёт. Справку, которая ещё собирается,
следующий запуск забирает по номеру заказа, без нового заказа. Если справок по счёту нет совсем — загружается
с 1 января текущего года (более раннюю историю удобнее загрузить файлами из кабинета).

Ключ хранится зашифрованным средствами Windows (расшифровать может только ваш пользователь на этом
компьютере) и в окне больше не показывается. Ключи с правом торговли программа не принимает, если вы явно
не разрешили; заявок программа не выставляет и таких функций не содержит. Журнал — api.log в папке данных.


Где данные
----------
%LOCALAPPDATA%\BrokerReport\reports — загруженные справки, \cache — кэш разбора, api.json — зашифрованные
ключи API, api-state.json и api.log — состояние и журнал автозагрузки.
Кнопки «удалить» (счёт) и «Удалить все данные» на странице «Счета» стирают их.


Сборка из исходников
--------------------
Нужен Python 3.12.

    python -m venv .venv
    .venv\Scripts\pip install -r requirements.txt pyinstaller pytest
    .venv\Scripts\python -m pytest tests
    .venv\Scripts\python build.py

Без сборки: .venv\Scripts\python app.py


Версии
